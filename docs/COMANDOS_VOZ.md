## 📝 Notas Importantes

### Para usar WolframAlpha:
1. ✅ Debes tener configurada la API key en el archivo `.env`
2. ✅ Variable: `WOLFRAM_API_KEY=tu_api_key_aqui`
3. ✅ Obtén tu API key gratuita en: https://products.wolframalpha.com/api/

### Palabras clave que activan WolframAlpha:
- "cuánto es", "calcula", "resuelve"
- "convierte", "pasa", "cuántos"
- "derivada", "integral"
- "velocidad de", "distancia de", "población de"
- "cuál es el valor de"

### Palabras clave para info del sistema:
- "IP", "dirección IP"
- "estado del ordenador/sistema"
- "CPU", "procesador"
- "RAM", "memoria"
- "disco", "espacio"

## 🔧 Troubleshooting

### WolframAlpha no responde:
- Verifica que `WOLFRAM_API_KEY` esté configurada en `.env`
- Asegúrate de tener internet
- Comprueba que no hayas excedido las 2,000 consultas/mes

### No reconoce el comando:
- Habla claro y pausado
- Repite el comando con palabras más simples
- Ejemplo: En lugar de "hazme un cálculo de...", di "calcula..."

## ✨ Consejos para Mejores Resultados

1. **Sé específico:** "Convierte 100 km a millas" es mejor que "convierte distancia"
2. **Usa números:** "25 por 37" es mejor que "veinticinco por treinta y siete"
3. **Pausas:** Deja una pequeña pausa después de "JARVIS" antes del comando
4. **Natural:** Habla de forma natural, no robotizada
